Arrhythmias & Conduction Problems

Stable vs. unstable — the #1 priority assessment

Unstable = low BP, altered LOC, chest pain, poor perfusion → treat immediately. Stable = hemodynamically intact. Symptomatic = patient feels it (dizzy, SOB, syncope) → treat. Asymptomatic = monitor only.

The earliest sign isn't BPHeart rate rises before BP ever drops. If you're only watching BP, you miss the most reversible window.

The 4-step rhythm formula

  • Rate — count R points in a 6-second strip × 10
  • Rhythm — regular or irregular?
  • P wave — present before every QRS?
  • QRS — normal, narrow, or wide/bizarre?

PR interval normal = 0.12–0.20 sec. U wave = hypokalemia.

Cardioversion vs. defibrillation — the #1 rule

Defibrillation = PULSELESSV-fib, pulseless V-tach — unsynchronized, high joules, given whenever ready.
Cardioversion = UNSTABLE WITH A PULSEA-fib, A-flutter, V-tach with a pulse — synchronized to the R point, lower joules. Pre-op: NPO, continuous ECG, O2 available, sedation given.

Medication pairings

  • Atropine → symptomatic bradycardia only, never asymptomatic
  • Beta blockers / diltiazem → A-fib rate control
  • Amiodarone → VT, VF, A-fib
  • Adenosine → atrial flutter (slows conduction)
  • Magnesium sulfate → Torsades de Pointes

Patient found down / pacemakers / post-op cardiac pain

  • Patient on the floor → call for help → check carotid pulse → CPR if pulseless
  • Pacemaker teaching: avoid MRI and magnets, carry ID card; post-op minimize activity to prevent electrode dislodgement
  • Post-op cardiac/abdominal surgery pain interfering with coughing → splint the incision with a pillow
  • O2 with chest pain → reduces myocardial workload, supports oxygen delivery to ischemic tissue
